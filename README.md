# BBQ Renamax — сайт

Сайт точки **BBQ Renamax** (ТІР-бочка, 339 км траси Київ–Чоп, с. Велика Омеляна).
Статичний: HTML + CSS + трохи JS, без збірки й залежностей.

## Структура

| Файл | Що це |
|---|---|
| `index.html` | сам сайт |
| `content.json` | **увесь змінний контент**: телефон, графік, меню, ціни, банер-оголошення, налаштування замовлень |
| `content.js` | підставляє content.json у сторінку |
| `order.js` | онлайн-замовлення: кошик у меню, форма, відправка |
| `worker/order-relay.js` | серверна частина замовлень (Cloudflare Worker) → Telegram |
| `admin.html` | форма редагування (відкривається як `адреса-сайту/admin.html`) |
| `img/logo.jpg` | логотип |

## Як оновити меню/ціни/графік

**Спосіб 1 (через адмінку):**
1. Відкрийте `https://<адреса-сайту>/admin.html`
2. Змініть поля → «Зберегти» — скачається новий `content.json`
3. Тут, на GitHub: відкрийте `content.json` → олівець **Edit** → вставте вміст скачаного файлу → **Commit changes**

**Спосіб 2 (одразу на GitHub):** відкрийте `content.json` → **Edit** → поправте текст (назву страви, ціну) → **Commit changes**. Через ~1 хв зміни на сайті.

Ціна страви — у форматі `650 грн/кг` (сайт сам рахує суму замовлення). Додаток із ціною — `Соус сакартвело - 150 грн`.

## Онлайн-замовлення → Telegram

Як це працює: клієнт тисне «+» біля страв → «Оформити» → ім'я, телефон, час → замовлення йде на
Cloudflare Worker → той пересилає його власнику в Telegram. Токен бота зберігається лише у воркері,
на сайті його немає.

Подивитися форму без відправки: `https://webrenamax-lgtm.github.io/bbq-renamax/?demo`

### Налаштування (один раз, ~10 хв)

1. **Бот.** У Telegram відкрийте @BotFather → `/newbot` → назва (напр. «BBQ Renamax Замовлення») і username
   (закінчується на `bot`) → скопіюйте **токен**.
2. **Хто отримує.** Власник відкриває свого бота й тисне **Start** (без цього бот не може йому писати).
   Потім у браузері відкрийте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайдіть `"chat":{"id":…` — це **CHAT_ID**.
   Для кількох людей: створіть групу, додайте бота, напишіть у групі `/start` — id групи від'ємний (`-100…`).
   Можна вказати кілька id через кому.
3. **Воркер.** dash.cloudflare.com (безкоштовно) → Workers & Pages → Create → Worker → назва `bbq-renamax-orders` → Deploy →
   **Edit code** → вставте вміст `worker/order-relay.js` → Deploy.
   Далі Settings → Variables and Secrets → додайте:
   - `BOT_TOKEN` (Secret) — токен з кроку 1
   - `CHAT_ID` (Secret) — id з кроку 2
   - `ALLOWED_ORIGINS` (Text) — `https://webrenamax-lgtm.github.io`

   Скопіюйте адресу воркера: `https://bbq-renamax-orders.<ваш-піддомен>.workers.dev`
   (альтернатива дашборду — `worker/wrangler.toml`, `npx wrangler deploy`).
4. **Сайт.** У `content.json` → `"order"` → `"endpoint"` вставте адресу воркера → Commit.
   Через хвилину на сайті з'являться кнопки «+» і кошик.
5. **Перевірка.** Зробіть тестове замовлення — повідомлення має прийти в Telegram.

### Керування

- Тимчасово вимкнути замовлення: адмінка → «Онлайн-замовлення» → зняти галочку (або `"enabled": false`).
- Крок ваги: `"step_kg"` (за замовчуванням 0.5 кг).
- Години для вибору часу беруться з першого робочого рядка графіка; інші можна задати як `"hours": "10:00-19:00"` у блоці `order`.
- Захист від спаму: перевірка домену, ліміт 8 замовлень з однієї IP за 10 хв, приховане поле-пастка, валідація.
- Якщо щось не працює — Cloudflare → воркер → Logs: там видно відповіді Telegram (напр. `chat not found` = неправильний CHAT_ID або власник не натиснув Start).
